# Banner Integration (PHP + JavaScript)

## 📌 Overview
This project provides a simple PHP-based banner integration system that can be embedded into any website.

## 🚀 Features
- Fetches banners dynamically from a MySQL database.
- Provides a JavaScript script to integrate banners into any webpage.
- Supports customizable **width, height, and position**.

## 🛠️ Setup Instructions
1. Import the **database.sql** file into your MySQL database.
2. Update `api/banner_api.php` with your **database credentials**.
3. Upload the project to your server.
4. Embed the script in any third-party website:
   ```html
   <script src="https://yourdomain.com/assets/banner.js"></script>
